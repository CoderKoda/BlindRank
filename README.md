# BlindRank
Blind ranking website!

Features:
This website will include a homepage with a description and a play button
There will be a log in page for users to create accounts to save their games and statistics
There will be a page where users can choose the categories of blind rankings they want to do. Potentially there may be a feature where AI can generate blind ranking items for a category that the user chooses.
There will be a page where users can view other users' statistics and compare them to their own
There will be a pge where the users will literally just pla the game
There will be a game over page where the user can review, share and post their blind ranking results. Potentially there may be a feature where AI can rate the user's blind ranking out of 10, one without accounting for order, and one with accounting for order of items shown and those can both be statistics categories
There will be a page for global settings such as colour scheme, dark/light mode, etc.
